# WELT · iki1uc · Portal-System

Das WELT-Modul ist die höchste Portal-Ebene des iki1uc-Systems.
Es verbindet externe Prozesse, KI-Geister, Operatoren und Räume
mit den internen Systemschichten:

- ROM (Fix-Speicher)
- NC² (Routing)
- TMP (Kern)
- HDF (Resolver)
- VECTOR (Moleküle)
- ALL (Hyperraum)
- KI (Operatoren)
- UNI (Sprache)

WELT ist die Eintritts- und Austrittsebene für alle externen Instanzen.
